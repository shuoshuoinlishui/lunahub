📖 使用说明 — Lunahub

👋 欢迎来到 Lunahub

这是一个仿 Windows XP 的网页桌面环境，集合了论坛、媒体、办公小工具。下面是快速上手指南。

🔑 账号

  • 点左下「开始 → 登录」可登录或注册。未登录以游客身份浏览。
  • 发帖、回复、聊天、上传壁纸/媒体需要先登录。
  • 忘记密码请联系管理员，在「管理后台 → 用户管理 → 重置密码」修改。

🖱️ 打开应用

  • 桌面图标：双击图标打开（我的电脑、PowerPoint、Excel 等）。
  • 开始菜单：左下「开始」→ 程序列表里点对应项。
  • 快速启动栏：任务栏左侧的小图标，单击即开。

💼 办公工具

  • 计算器：仿 XP 标准计算器，支持内存键 MC/MR/MS/M+、√、x²、%、括号。
  • PowerPoint：简易幻灯片，可加文字/图片、拖拽排序、导出 JSON。
  • Excel：单元格可输入数字或 = 公式，支持单元格引用与 SUM/AVG/MIN/MAX。

🌐 社区

  • 论坛分区：按板块浏览话题，点「进入全部」看所有帖。
  • 在线聊天：登录后可发消息，实时同步。
  • 画廊 / 媒体播放器：浏览图片与音乐视频。

🎨 个性化

  • 「外观和个性化」可换壁纸、主题、窗口颜色、字体大小、鼠标指针皮肤。
  • 管理员可在「管理后台」配置开机/关机音效。

关机请点「开始 → 关机」，可选择关机 / 重启 / 睡眠。
